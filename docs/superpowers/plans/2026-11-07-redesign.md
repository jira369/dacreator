# Redesign dacreator.dev Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Komplettes Redesign von dacreator.dev als hell-editoriale, motion-starke Seite für Dac Vu, Head of Performance Marketing, Deutsch als Default.

**Architecture:** Astro-Seiten pro Locale rendern neue Sektions-Komponenten. Alle Texte kommen aus `src/i18n/ui.ts`. Motion läuft über ein gebündeltes GSAP-Modul im `BaseLayout`, Hero und Zähler als React-Inseln.

**Tech Stack:** Astro 6, React 19, Tailwind 4, GSAP 3.14 (ScrollTrigger), Framer Motion 12, MDX Collections.

**Spec:** `docs/superpowers/specs/2026-11-07-redesign-design.md`

## Global Constraints

- Skills vor jeder UI-Arbeit laden: `anthropic-skills:impeccable`, `anthropic-skills:design-taste-frontend`. Vor Abschluss deren Prüflisten durchlaufen.
- Texte nur in `src/i18n/ui.ts`, nie hart in Komponenten.
- `defaultLocale` ist `de`. Locales: `de`, `en`, `vi`. `/` leitet auf `/de` weiter.
- Titel: "Head of Performance Marketing". Nie "Head of Creative & Brand" als Titel.
- Zahlen exakt: "60 Mio" Jahresumsatz, "ca. 3 Mio" Spend, "über 40 Mio" Streitwert, "4 Monate". Wachstum: "Von niedrigem 7-stelligen Umsatz auf 60 Mio Jahresumsatz durch Performance Marketing." Keine Jahreszahlen.
- Keine Teamnamen, KPIs, Entscheidungsmatrix, Gehälter. Private Repos (marketingcockpit, utm-generator, sea-cockpit): Card ohne Link, Badge "intern".
- Barrierefrei: Kontrast AA, `prefers-reduced-motion` schaltet jede Animation ab, Fokus sichtbar.
- Mobile-first, kein horizontaler Scroll. Animation nur über transform und opacity.
- Keine Gedankenstriche in Texten. Tonalität: kurz, direkt, Du, keine Floskeln.
- Commit-Nachrichten enden mit den vorgegebenen Attributionszeilen. Push nur auf `claude/epic-carson-mmea43`.

## Review Focus

- Aufruf von `/` und `/vi` ohne Trailing Slash: Redirect auf `/de` bzw. gültige Seite, kein 404.
- `prefers-reduced-motion: reduce`: alle Inhalte sichtbar, Zähler zeigen Endwert sofort.
- Fehlende Übersetzung (vi): Fallback auf DE, nie leerer Text oder Key-Name.
- Sehr schmales Display (320px): Hero-Typo und Marquee laufen nicht über.
- JS aus: Inhalte bleiben lesbar (Elemente per `data-animate` nicht dauerhaft `opacity: 0`).
