# Warum ich diese Seite gebaut habe

Jeder digitale Profi braucht ein Zuhause im Web. Nach Jahren der Arbeit mit verschiedenen Plattformen habe ich beschlossen, etwas von Grund auf zu bauen — etwas, das wirklich repräsentiert, wer ich bin und was ich mache.

## Der Tech Stack

Ich habe **Astro** als Grundlage gewählt, weil es standardmäßig kein JavaScript ausliefert. Für eine Portfolio-Seite bedeutet das:

- **Blitzschnelle Ladezeiten** — statisches HTML mit selektiver Hydration
- **Perfektes SEO** — vollständig gerendertes HTML, keine Client-Side SPA
- **React wo ich es brauche** — interaktive Komponenten wie Animationen nutzen weiterhin React

Kombiniert mit **Tailwind CSS** für das Styling und **Framer Motion** für Animationen liefert dieser Stack ein Agentur-Erlebnis mit minimalem Overhead.
